# Punit ERP Codex Project Prompt

Open the cloned `punittechnologies/puniterp26` repository as the Codex workspace.
Start every development task by pasting the complete prompt from
`docs/EMPLOYEE_CODEX_START_PROMPT.md`, followed by one specific requested
change and measurable acceptance criteria.

Codex must read, in this order:

1. `AGENTS.md`
2. `docs/PROTECTED_FEATURE_BASELINE.md`
3. `docs/SYSTEM_FEATURE_CATALOG.md`
4. Relevant source, routes, migrations and tests

The current repository is the source of truth. Do not upload an APK, an old
Hostinger folder, screenshots or a partial backup as a replacement codebase.
Do not give Codex production credentials in the task prompt.

The exact copy/paste task template and owner review checklist are maintained in
`docs/EMPLOYEE_CODEX_START_PROMPT.md`; do not maintain a second divergent copy.
